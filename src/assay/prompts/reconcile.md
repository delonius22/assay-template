# Task: reconcile developer answers

Check each answer against the questionnaire, the other answers, and the code.

- Confirmed or corrected: record a decision.
- Conflicting: record an open question with each respondent's position.
- Unknown and not blocking: record an assumption using the proposed answer.
- Unknown and blocking: list it as a blocking gap.
- Reveals a new risk: record a risk.
List contradictions explicitly. Follow-up questions only for blocking gaps,
eight at most. Set the same typed fields as in grilling (scope_side,
journey_path, metric, covers_rollback, owners).
