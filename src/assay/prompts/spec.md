# Task: write the developer spec

Name modules and interfaces with glossary terms; no file paths or code.
For every interface, state behaviour on timeout, invalid input, duplicate
request, and dependency outage. Security, access, and audit are design, not
afterthoughts. If a PRD requirement is infeasible or contradictory, say so
in prd_issues. Coverage must list every FR- and NFR- ID with the spec
sections that address it.
